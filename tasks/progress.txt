## Codebase Patterns
- Use pnpm as package manager with workspaces
- Use turbo for build orchestration across packages
- TypeScript config extends tsconfig.base.json in each package
- Each package has `build`, `typecheck`, `lint`, `test`, and `clean` scripts
- ESLint v8 with @typescript-eslint for linting
- Package naming: `@unknit/<package-name>`
- Vitest for unit testing with `vitest.config.ts` in each package
- Test files use `*.test.ts` suffix in `src/` directory
- Use `??` for default values when accessing array indices to satisfy strict TypeScript
- Avoid `while(true)` loops - use explicit condition to avoid ESLint `no-constant-condition`
- Export classes with `export class` and helper functions with `export function`
- VS Code extensions use CommonJS output (module: "CommonJS" in tsconfig) and esbuild for bundling
- VS Code extension names use unscoped format (e.g., `unknit-vscode` not `@unknit/vscode`)
- VS Code CustomTextEditorProvider requires viewType matching package.json contributes.customEditors
